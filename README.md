# Бюро нотаций – один процесс, семь чертежей

Мини-wiki по методам моделирования бизнес-процессов: **Flow Chart, DFD, RAD, IDEF, ERD, UML, BPMN**.
Для каждой нотации – краткое описание, элементы нотации, правила составления, пример и ссылки на источники.
Во всех примерах – один общий процесс: **обработка заказа в интернет-магазине**.

Сайт: https://starpxand.github.io/bpm-blueprint-wiki/

Это вторая, «чертёжная» версия командной мини-wiki ([bpm-modeling-wiki](https://github.com/starpxand/bpm-modeling-wiki)):
тексты и источники те же, а подача другая – каждая диаграмма оформлена как лист чертежа со штампом
с полноэкранным просмотром и масштабом. Обложка – полёт сквозь альбом из семи листов, управляемый прокруткой
(scroll-scrub); затем заказ проходит по процессу шаг за шагом.

## Что можно сделать на сайте

- **Пролететь альбом.** Прокрутка ведёт камеру сквозь семь листов; у каждого – пауза для чтения, затем лист
  перелистывается вокруг левого края. Клавиши <kbd>1</kbd>–<kbd>7</kbd> переносят прямо к нужному листу.
- **Найти что угодно.** <kbd>/</kbd> или <kbd>Ctrl</kbd>+<kbd>K</kbd> – поиск по листам, разделам, источникам и
  каждому элементу нотаций («шлюз», «хранилище данных», «воронья лапка»); переход подсвечивает найденную строку.
- **Рассмотреть схему.** <kbd>Shift</kbd> над диаграммой или кнопка с лупой – лупа чертёжника ×2,5;
  двойной щелчок – лист во весь экран с масштабом колесом.
- **Вести зачётку.** Дочитанный до конца лист получает печать «Изучено» на месте «М. П.», в меню появляется
  отметка, на главной – ведомость «изучено N из 7». Хранится только в этом браузере.
- **Сравнить два чертежа.** На странице «Сравнение» – шторка: два листа альбома друг над другом,
  разделитель тянется мышью, пальцем или стрелками.
- **Проверить себя.** «Тренажёр» – 10 фрагментов чертежей, угадайте нотацию (кнопками или 1–7).
  «Отдалить» показывает фрагмент шире за ½ балла; после ответа фрагмент отъезжает до целого листа и рамкой
  показывает, откуда он взят. От 7 баллов – свидетельство в формате листа A4 для печати или PDF.

## Сборка

```bash
pip install -r requirements.txt
python build.py          # content/*.md -> site/
python -m http.server -d site 8000
```

GitHub Actions собирает сайт и публикует его на GitHub Pages при каждом push в `main`.

## Устройство

| Путь | Назначение |
|---|---|
| `content/` | тексты нотаций, сравнения и источников (Markdown, общие с командной wiki) |
| `assets/img/` | SVG-диаграммы DFD, RAD, IDEF0, IDEF3, UML, BPMN |
| `assets/css/site.css` | оформление «чертёжный стол»: синька, листы на бумаге, штамп |
| `assets/js/scrub.js` | появление блоков, липкое оглавление, лист во весь экран с масштабом |
| `assets/js/fx.js` | плавная прокрутка Lenis, магнитные кнопки, горячие клавиши, печать бюро |
| `assets/js/search.js` | поиск по альбому; индекс `assets/search.json` собирает `build.py` |
| `assets/js/album.js` | зачётка: печать «Изучено», отметки в меню и ведомость на главной |
| `assets/js/loupe.js` | лупа чертёжника над диаграммами |
| `assets/js/curtain.js` | шторка «один процесс – два чертежа» на странице сравнения |
| `assets/js/trainer.js` | тренажёр «Узнай нотацию» и свидетельство |
| `assets/js/flight.js` | обложка: полёт сквозь альбом листов с перелистыванием |
| `assets/js/home.js` | сюжет главной: маршрут заказа и «веер» из семи нотаций – ссылок на листы |
| `assets/js/mermaid-init.js` | Mermaid 11 для Flow Chart, ERD и UML |
| `build.py` | сборщик страниц |

Анимации отключаются, если в системе включено «уменьшение движения» (`prefers-reduced-motion`).
