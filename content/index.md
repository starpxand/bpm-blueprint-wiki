# Методы моделирования бизнес-процессов

Модель бизнес-процесса – упрощённое графическое представление того, **кто, что, в какой
последовательности и с какими данными** делает, чтобы получить результат для клиента.
Разные нотации отвечают на разные вопросы, поэтому в проектах их комбинируют.

Во всех примерах используется один общий процесс – **обработка заказа в интернет-магазине**:
клиент оформляет заказ, менеджер проверяет наличие и выставляет счёт, клиент оплачивает,
склад собирает заказ, служба доставки доставляет, клиент получает заказ. Один пример во всех
нотациях позволяет наглядно сравнить, что каждая из них показывает лучше других.

## Как устроена каждая страница

| Раздел | Содержание |
|---|---|
| Описание | назначение нотации, происхождение, стандарт, когда применять и ограничения |
| Элементы нотации | таблица обозначений |
| Правила составления | как строить корректную диаграмму |
| Пример | процесс обработки заказа в интернет-магазине в этой нотации |
| Ссылки на источники | источники, оформленные по ГОСТ Р 7.0.100-2018 |

!!! tip "Диаграммы живые"
    Диаграммы появляются с анимацией при прокрутке. Кнопка **«⤢ Увеличить»** (или двойной щелчок)
    открывает диаграмму во весь экран с масштабом и перемещением; на странице BPMN модель можно
    пройти по шагам кнопкой **«▶ Пройти процесс»**.
